Use when data ARRIVING from a producer you do not control must be checked before anything downstream trusts it — a vendor feed, an API sync, a CSV/JSON/Parquet drop, an event stream, a nightly ETL load. Profiles the batch, derives an explicit contract, asserts it at the ingest boundary, and splits every difference into the ones that stop the batch and the ones that legitimately widen it. Triggers on 'the numbers look wrong but nothing errored', 'upstream changed something and nobody told us', 'a column silently changed units', 'half the rows are null today', 'a category we have never seen', 'set a drift threshold', 'alerts so noisy we muted them', 'which dbt / Great Expectations / Soda checks to write'. NOT validating a model's own output against a schema (structured-llm-extraction), NOT the mirror sides of a code contract in a patch (integration-contract-completeness), NOT picking eval-set examples (eval-set-curation), NOT training or serving code in a diff (mlops-production-review).
