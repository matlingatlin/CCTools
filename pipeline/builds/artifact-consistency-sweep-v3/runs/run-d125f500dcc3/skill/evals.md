### Why abandon, in one line

The review loop did not converge: each rewrite removed the previous round's class findings and the next review found a new set of comparable size (7, 9, 11), so the text was never in a state the contract lets the arms measure. The bare baseline, once its prompt stopped dictating a shape, already clears the recall bars on five of six runs; what it lacks is the ledger, the matrix and precision - the shape the skill exists to add - and that could not be measured on a text still red at class level.
