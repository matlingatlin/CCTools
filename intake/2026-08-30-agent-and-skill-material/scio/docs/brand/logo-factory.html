Scio — the factory, four ways

Factory chosen. The owl stays, but it earns its place in the motion rather than sitting in the logo as a mascot. Four proposals below, each a different answer to one question: where is the owl while the machine is running?

state building

Proposal 1

The machine resolves into the owlrecommendation

While it builds, you see a machine: two meshing gears, a drive belt, two cylinders. When the build lands, the machinery fades and the same two gears are already sitting where eyes go — a beak and two tufts arrive, and the face was there the whole time. This is the one that is actually 4D: the form has an arc, and the payoff is the reveal, which is the product's own most important moment.

SCI

Owl is latent — present in every state, visible only when the machine stops. Survives to 16 px because the eyes are the largest shapes.

Proposal 2

The owl runs the machine

Two figures, not one. The machine is below — gear train, pistons, a belt. The owl sits on the beam above and watches it work: it blinks, it looks where the work is, and it never turns. Literal about the architecture we keep saying out loud — rules do what rules can guarantee, the model is used only for judgement. Costs the most detail, so it is a hero mark and a separate small mark is needed for favicons.

Owl is the operator — always visible, never part of the mechanism. Needs a reduced companion mark below 32 px.

Proposal 3

One gear, owl in the negative space

The quietest of the four and the only one that is unmistakably a logo rather than an illustration. A single gear; the hub cut-out is a face. The rim turns, the face does not. It scales to a favicon untouched and it will still look right in five years — but it gives up the factory reading almost entirely, which is what you asked for, so it is here as the conservative floor rather than as a contender.

SCIO

Owl is the mark itself. Safest, least said.

Proposal 4

Wordmark, with the machine inside the O

The mark is the word. O is a working port you can see into: gear, piston, belt, and two eyes deep in the housing that catch the light when the machine stops. Reads as a company rather than an app icon, which is the right register for something selling developer-impressed code — but a wordmark alone gives you nothing to put in a 32 px square, so it needs P1 or P3 beside it.

SCI

Owl is a glimpse — two eyes inside the port, only when the machine is at rest.

The part that outlives the drawing

Motion is bound to state, or it does not run

A mark that spins forever is decoration, and decoration is what every competitor already ships. If it turns only while work is happening, it becomes the cheapest honest signal in the product — and the diagnosis we wrote about the predecessor is precisely that it computes honest signals and drops them before anyone sees them. Use the bar at the top: every proposal is driven by the same six states.

Every shape here is an SVG path with no external asset, and every colour reads from a token rather than a literal — the same contract .claude/skills/app-design asks of every generated app. So the mark is a component the product drives from real build state, not an image file.

What the online scan changed, already applied here. A sixth state, failed — a build system with no visible failure state repeats the exact omission app-design §4 calls a quality bar, and failure is what a user most needs to read from a background tab. Reduced motion now reduces rather than deletes: machine opacity, owl presence and teeth colour are static, so all six states stay legible with every animation off. The done settle no longer animates scale, which is a vestibular trigger. Tooth dashes are computed from the circumference instead of rounded. State is announced to assistive technology.

Still open. CSS cannot ship this: changing animation-duration mid-flight makes thinking → building jump a full tooth — the transition the product performs most often. The scan's recommendation is the Web Animations API and updatePlaybackRate(), which syncs to current position and costs 0 KB. The CSS here is the fallback layer, not the mechanism.
